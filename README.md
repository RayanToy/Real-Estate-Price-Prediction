# Real-Estate-Price-Prediction
Анализ данных и построение моделей машинного обучения для прогнозирования стоимости квартир. Проект включает в себя исследовательский анализ, предобработку данных с заполнением пропусков с помощью моделей, инжиниринг признаков, а также сравнение и оптимизацию регрессионных моделей, включая CatBoost, LightGBM, XGBoost и PyTorch.

# Анализ рынка недвижимости и прогнозирование стоимости квартир

## О проекте

Этот проект представляет собой исследование данных о рынке недвижимости с целью выявления ключевых факторов, влияющих на стоимость квартир, и построения предиктивной модели машинного обучения. Анализ выполнен на наборе данных, содержащем объявления о продаже квартир в нескольких крупных городах России.

Основная цель работы — разработать модель, способную с высокой точностью прогнозировать цену за квадратный метр на основе характеристик объекта недвижимости.

## Структура проекта

*   `real_estate_price_prediction.ipynb` — Jupyter Notebook «Анализ и прогнозирование цены квадратного метра жилплощади в различных городах»: весь код для анализа данных, их предобработки, визуализации, построения и оценки моделей.
*   `data/flats.csv` — исходные данные (описание — в разделе «Данные»).
*   `features.py` — построение признаков; общий код для ноутбука и `predict.py`.
*   `predict.py` — прогноз цены квадратного метра для новых квартир.
*   `models/price_model.joblib` — обученная модель для `predict.py` (её создаёт ноутбук).
*   `requirements.txt` — список необходимых библиотек с версиями, на которых проверен ноутбук.
*   `README.md` — данный файл с описанием проекта.

## Данные

`data/flats.csv` — 6 691 объявление о продаже квартир (у 6 690 указана цена), 61 столбец. Дробные числа в части столбцов записаны через запятую (`55,752364`), логические значения — `True`/`False` (в некоторых столбцах строчными буквами).

| Город | Объявлений |
|---|---|
| Казань | 2 923 |
| Санкт-Петербург | 1 788 |
| Москва | 1 372 (+19 в посёлках Новой Москвы: Сосенское, Мосрентген, Московский) |
| Новосибирск | 589 |

**Целевая переменная** — `price_sq`, цена за квадратный метр в рублях: медиана 179 тыс., от 21 тыс. до 735 тыс.

**Основные столбцы** (в скобках — доля заполненных значений, если она меньше 100%):

| Столбец | Описание |
|---|---|
| `id`, `offer_views` | идентификатор и число просмотров объявления (в модели не используются) |
| `city`, `lat`, `lon` | город и координаты дома |
| `area`, `kitchen_area` | общая площадь и площадь кухни, м² (кухня 0 — значение не указано) |
| `rooms` | число комнат (0 — студия) |
| `floor`, `house_floors` | этаж и этажность дома |
| `build_year` | год постройки (87%) |
| `house_wall_type` | материал стен: кирпичный, панельный, монолитный и др. (97%) |
| `bathroom_type` | санузел: совмещённый, раздельный, более одного (22%) |
| `balconies`, `lifts`, `freight_lifts` | число балконов, пассажирских и грузовых лифтов |
| `time_on_foot_to_subway` | время пешком до метро, мин (55%) |
| `renovation` | ремонт, свободный текст: «косметический», «требует ремонта» и др. (54%) |
| `is_apartment` | апартаменты, а не квартира (80%) |
| `has_gas` | газ в доме (64%) |
| `sale_type` | тип продажи: свободная продажа, альтернатива, переуступка, от застройщика (75%) |
| `urgent`, `is_auction`, `duplicates_count` | срочная продажа, продажа с торгов, число дублей объявления |

**Столбцы `all_data.*`** — вложенные поля объявления:

*   `all_data.house.*` — дом: высота потолков (30%), мусоропровод (50%);
*   `all_data.object_info.*` — квартира: жилая площадь (65%), лоджии (15%), перепланировка (25%), тип парковки (4%);
*   `all_data.legal_options.*` — юридические сведения: признак `approve` (заполнен везде), ипотека, число собственников, срок владения, несовершеннолетние собственники и прописанные и др. (15–34%);
*   столбцы-списки `window_view[0..4]`, `security[0..3]`, `parking[0..4]`, `yard[0..1]`, `infrastructure[0..4]` — вид из окна, безопасность, парковка, двор, инфраструктура рядом; каждое значение списка лежит в отдельном столбце, порядок значений смысла не несёт (заполнены у 19–43% объявлений).

## Прогноз для новых квартир

На вход — таблица квартир в формате исходного CSV. Обязательны столбцы `city`, `lat`, `lon` и `area`; остальные можно не заполнять, но чем больше заполнено, тем точнее прогноз.

```python
import pandas as pd
from predict import predict_price

flats = pd.read_csv('new_flats.csv')
flats['predicted_price_sq'] = predict_price(flats)
```

Из командной строки:

```bash
python predict.py new_flats.csv predictions.csv
```

Для прогноза используется отдельная модель без импутации пропусков и признака `cluster`: на качество они не влияют (R² на кросс-валидации 0.869, на тесте 0.905, MAPE 9.2% — как у итоговой модели), а без них признаки собираются прямо из исходной таблицы. Модель обучена на объявлениях Москвы, Санкт-Петербурга, Казани и Новосибирска; для других городов прогноз не имеет смысла.

## Этапы работы

1.  **Исследовательский анализ данных (EDA)**:
    *   Проведено изучение структуры и распределения данных. Выявлено, что целевая переменная (цена за квадратный метр) имеет бимодальное распределение, обусловленное географическими и временными факторами (разные рынки городов и года постройки).
    *   С помощью визуализаций и статистических тестов (тест Краскела-Уоллиса, корреляция Спирмена) проанализировано влияние различных признаков на цену.

2.  **Предобработка и инжиниринг признаков**:
    *   Выполнена очистка и стандартизация данных, включая приведение текстовых категорий к единому формату.
    *   Для заполнения пропущенных значений в ключевых столбцах (`build_year`, `house_wall_type`, `bathroom_type` и др.) применён подход с обучением моделей `CatBoost`, что позволило сохранить данные без значительных потерь. Отдельная проверка показала, что на качество итоговой модели импутация почти не влияет: `LightGBM`, оставляющий пропуски как есть, даёт тот же результат в пределах разброса между фолдами.
    *   Сгенерирован новый признак `cluster` с помощью алгоритма `KMeans`, основанный на географических координатах, времени до метро и годе постройки. Он призван учесть локальные особенности районов, но заметного прироста качества по проверке не даёт.
    *   Добавлены признаки, которые дали основной прирост качества: расстояние и направление от центра города, повёрнутые координаты (деревья делят пространство только вдоль осей), этаж относительно этажности, доля жилой площади, высота потолков, тип продажи и флаги из столбцов-списков (вид из окна, парковка, безопасность, двор, инфраструктура).

3.  **Сравнение и выбор модели**:
    *   Проведено сравнение нескольких регрессионных моделей: `RandomForest`, `CatBoost`, `XGBoost`, `LightGBM`, `Ridge` и нейронной сети на `PyTorch`.
    *   Все модели оцениваются с разбиением по домам: квартиры одного дома попадают либо в обучающую, либо в тестовую выборку. Так метрики показывают качество прогноза для домов, которых модель не видела.
    *   Лучшие результаты показали модели градиентного бустинга: `CatBoost`, `XGBoost` и `LightGBM` близки друг к другу (R² 0.88–0.89 на тесте).

4.  **Оптимизация и финальная модель**:
    *   Модели учатся на логарифме цены: ошибка считается в относительных величинах, как MAPE.
    *   Для модели `LightGBM`, показавшей одну из лучших базовых метрик и высокую скорость, был произведен подбор гиперпараметров с использованием `Optuna` и 5-кратной кросс-валидации по домам на обучающей части. Тестовая выборка в подборе не участвует.
    *   Итоговый прогноз — среднее `LightGBM` с подобранными параметрами и `CatBoost`: модели ошибаются на разных квартирах, и их среднее точнее каждой по отдельности.


## Результаты

Итоговый ансамбль `LightGBM` + `CatBoost` показал следующие метрики на тестовом наборе данных (20% домов, не участвовавших в обучении):
*   **MAE**: 17984.06
*   **RMSE**: 28210.57
*   **R²**: 0.9043
*   **MAPE**: 9.11%

Средний R² на кросс-валидации по домам — 0.871 (MAPE 9.5%). Разница с тестом укладывается в разброс между разбиениями, поэтому как ориентир надёжнее значение кросс-валидации. Точнее всего модель работает в Санкт-Петербурге (MAPE на тесте 8.2%), хуже всего — в Новосибирске (10.8%).

Откуда качество (R² на кросс-валидации):

| Вариант | R² | MAPE |
|---|---|---|
| `LightGBM` на исходных признаках | 0.839 | 10.6% |
| + логарифм цены | 0.843 | 10.4% |
| + дополнительные признаки | 0.854 | 10.0% |
| + подбор гиперпараметров | 0.867 | 9.8% |
| + ансамбль с `CatBoost` | **0.871** | **9.5%** |

Проверены и не дали прироста: расстояние до ближайшей станции метро по данным OpenStreetMap (почти совпадает с имеющимся временем пешком до метро), средняя цена соседних квартир, отдельные модели для каждого города.

В первой версии проекта были указаны R² 0.93 и MAPE 7.65%. Эти цифры были завышены: квартиры одного дома попадали и в обучающую, и в тестовую выборку, ранняя остановка выполнялась по тестовой выборке, а в заполнении пропусков и в построении кластеров были ошибки. При случайном разбиении исправленная схема на исходных признаках даёт R² ≈ 0.927, но такая оценка не отражает качество для новых домов.

Наиболее важными признаками для модели оказались:
1.  **Координаты** (`lon`, `lat`)
2.  **Город** (`city`)
3.  **Площадь** (`area`)
4.  **Год постройки** (`build_year`)
5.  **Расстояние до центра города** (`dist_center_km`)
